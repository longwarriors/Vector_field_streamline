# 物理与数学建模教程

场线图很直观，也很容易画错、读错。色标可能缺少单位，线条疏密可能只由种子决定，三维曲线的二维投影也可能被误称为“截面上的真实场线”。本教程从定义出发，依次说明物理模型、数值积分和图形含义。

不需要先学完整的电动力学或广义相对论。读完整套教程后，你应该能回答三个问题：

1. 图上的曲线由哪条方程定义？
2. 程序近似了什么，误差从哪里来？
3. 用什么量能检查结果，而不只是凭图形判断？

## 统一记号

- $\mathbf x$：二维或三维位置。
- $\mathbf F(\mathbf x)$：位置处的向量场；具体问题中可以是 $\mathbf E$、$\mathbf B$ 或 $\mathbf g$。
- $\lVert\mathbf F\rVert$：场的大小。
- $s$：沿曲线量取的弧长参数。
- $\widehat{\mathbf F}=\mathbf F/\lVert\mathbf F\rVert$：场方向，只在非零场点定义。

所有公式默认使用 SI 单位；黑洞章节会明确改用 $G=c=1$ 的几何单位。代码中的坐标值只有在模型声明长度单位后才具有物理长度。

## 项目现在做到哪里

已经可用：

- 匀强场、点电荷场、理想磁偶极场及其线性叠加；
- 带误差控制和终止事件的二维、三维场线追踪；
- 电偶极子、磁偶极子和匀强场的浏览器二维展示；
- 场源 mask、终止原因、单位和切片说明。

还没有实现：

- 圆线圈的椭圆积分解析场与 Biot–Savart 数值求积；
- 规则网格、VTK、FEMM 数据导入；
- 三维交互渲染、LIC 和等通量播种；
- Schwarzschild/Kerr 零测地线与辐射传输。

相关章节只介绍建模与验证方法；尚未实现的接口会明确标注为计划项。
