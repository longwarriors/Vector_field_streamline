# 开发路线

本页只记录已经书面确认的近程范围。计划项不是当前能力；实际可用接口以 [API 参考](api.md) 为准。

## v0.2.1：发布基线

状态：**已完成**。

- 统一包元数据、运行时版本和 API 示例；
- 用 [CHANGELOG](https://github.com/longwarriors/Vector_field_streamline/blob/master/CHANGELOG.md) 汇总此前已交付的契约变化；
- 完成严格质量门禁及 wheel/sdist 隔离安装后，在发布提交上创建 annotated tag。

## v0.2.2：诚实性与契约修补

状态：**已完成**。

- 探针使用未裁剪的有限标量值，色标上下界只控制显示；
- masked 标量使用 JSON `null`，并补齐响应模型跨字段校验；
- density 控件改为整数步长 1，浏览器显示自由文本播种说明和终止统计；
- 通过预设 capability 公开 active 点源的严格最小中心距，并在服务端、数值编辑与拖动路径统一执行；
- 零强度偶极保留为非 active marker，全零磁场景返回 422；拖动期间不再把旧场与新源位置混画；
- 增加独立的 macOS + Python 3.13 非浏览器兼容任务。

## v0.3.0：播种科学性

状态：**已完成**。

- 正负电荷共同分配种子预算，并按实际源对覆盖抑制重复线族；
- 默认 Halbach 使用强弱两侧平行轨道覆盖播种，单磁偶极使用旋转赤道线覆盖播种；
- 圆环按磁通函数等 ψ 播种；只有这一真实通量坐标策略标记为 `equal_flux`；
- `seed_mode` 升级为枚举与说明文字，并明确 BOTH 轨迹的双端终止语义。

## v0.3.1：验收修正

状态：**已完成**。

- 单磁偶极赤道线播种按签字决定标为 `coverage`；`feature` 保留给真正的特征播种；
- 明确核心奇点政策：源几何决定奇点集合，与源强无关，零强度源由场景层剔除；
- 增加核心不依赖 Web 层的架构测试，补齐播种规划器与响应模型的参数校验覆盖。

## v0.3.2：白板界面

状态：**已完成**。

- 浅色白板界面：样式令牌、图在前的分栏布局、浮动工具胶囊和便签式场源卡，只提供浅色主题；
- 画布改为白纸，配套双环标记、未着色斜线与条件图例、色标截断尖角、坐标轴单位标题和图注播种信息；
- 修复热图纹素错位、画布焦点环被裁、窄屏色标压图和探针被裁；
- HTTP API 与 Python 代码不变。

## v0.3.3：性能 I

状态：**已完成**。

- 去掉单点求值时 NumPy 包装函数的开销，事件函数复用右端函数刚算过的场值；
- 圆环一般区域的单点求值改用 Python 浮点，近轴与奇点仍走批量路径；
- 服务端按“请求去掉 `resolution`”缓存追踪结果，只改分辨率时不再重新追踪；
- 在验证过的场景与对抗输入上，输出与 v0.3.2 逐位相同，HTTP API 不变；验证范围与前后基准见[开发指南](development.md#v033-benchmark)。

## v0.3.4：场线图配色

状态：**已完成**。

- 热图改用明度单调的淡紫色阶，场越强颜色越深；场线与方向箭头改为带白边的黑墨线；
- 场源标记与便签改用与淡紫区分得开的粉、蓝、浅黄、绿，界面不再使用青绿色；
- 未着色格点改为与色阶明显不同的中灰斜线；有未着色格点时，热图只在有色格点之间插值，颜色不再跨过遮罩渐变或串色；
- 所有有效格点同值的恒定场画色阶中间色；HTTP API 与 Python 代码不变。

后续的矢量图层、网格导入、三维视图与相对论动力学分别属于更晚版本，不纳入上述里程碑。
