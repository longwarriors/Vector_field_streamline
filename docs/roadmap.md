# 开发路线

本页只记录已经书面确认的近程范围。计划项不是当前能力；实际可用接口以 [API 参考](api.md) 为准。

## v0.2.1：发布基线

状态：**已完成**。

- 统一包元数据、运行时版本和 API 示例；
- 用 [CHANGELOG](https://github.com/longwarriors/Vector_field_streamline/blob/master/CHANGELOG.md) 汇总此前已交付的契约变化；
- 完成严格质量门禁及 wheel/sdist 隔离安装后，在发布提交上创建 annotated tag。

## v0.2.2：诚实性与契约修补

状态：**已完成**。

- 探针使用未裁剪的有限标量值，色标上下界只控制显示；
- masked 标量使用 JSON `null`，并补齐响应模型跨字段校验；
- density 控件改为整数步长 1，浏览器显示自由文本播种说明和终止统计；
- 通过预设 capability 公开 active 点源的严格最小中心距，并在服务端、数值编辑与拖动路径统一执行；
- 零强度偶极保留为非 active marker，全零磁场景返回 422；拖动期间不再把旧场与新源位置混画；
- 增加独立的 macOS + Python 3.13 非浏览器兼容任务。

## v0.3.0：播种科学性

状态：**已完成**。

- 正负电荷共同分配种子预算，并按实际源对覆盖抑制重复线族；
- 默认 Halbach 使用强弱两侧平行轨道覆盖播种，单磁偶极使用旋转赤道线覆盖播种；
- 圆环按磁通函数等 ψ 播种；只有这一真实通量坐标策略标记为 `equal_flux`；
- `seed_mode` 升级为枚举与说明文字，并明确 BOTH 轨迹的双端终止语义。

## v0.3.1：验收修正

状态：**已完成**。

- 单磁偶极赤道线播种按签字决定标为 `coverage`；`feature` 保留给真正的特征播种；
- 明确核心奇点政策：源几何决定奇点集合，与源强无关，零强度源由场景层剔除；
- 增加核心不依赖 Web 层的架构测试，补齐播种规划器与响应模型的参数校验覆盖。

## v0.3.2：白板界面

状态：**已完成**。

- 浅色白板界面：样式令牌、图在前的分栏布局、浮动工具胶囊和便签式场源卡，只提供浅色主题；
- 画布改为白纸，配套双环标记、未着色斜线与条件图例、色标截断尖角、坐标轴单位标题和图注播种信息；
- 修复热图纹素错位、画布焦点环被裁、窄屏色标压图和探针被裁；
- HTTP API 与 Python 代码不变。

## v0.3.3：性能 I

状态：**已完成**。

- 去掉单点求值时 NumPy 包装函数的开销，事件函数复用右端函数刚算过的场值；
- 圆环一般区域的单点求值改用 Python 浮点，近轴与奇点仍走批量路径；
- 服务端按“请求去掉 `resolution`”缓存追踪结果，只改分辨率时不再重新追踪；
- 在验证过的场景与对抗输入上，输出与 v0.3.2 逐位相同，HTTP API 不变；验证范围与前后基准见[开发指南](development.md#v033-benchmark)。

## v0.3.4：场线图配色

状态：**已完成**。

- 热图改用明度单调的淡紫色阶，场越强颜色越深；场线与方向箭头改为带白边的黑墨线；
- 场源标记与便签改用与淡紫区分得开的粉、蓝、浅黄、绿，界面不再使用青绿色；
- 未着色格点改为与色阶明显不同的中灰斜线；有未着色格点时，热图只在有色格点之间插值，颜色不再跨过遮罩渐变或串色；
- 所有有效格点同值的恒定场画色阶中间色；HTTP API 与 Python 代码不变。

## v0.3.5：内容 I

状态：**已完成**。

- 三个电荷排布预设（电四极子、六个正电荷、三对交替电荷）与电偶极共用点电荷契约；点电荷场景的零场终止阈值改为与场景量级匹配的 $10^{-6}\ \mathrm{V/m}$，落入零场点的线以 `null_field` 停在零点；
- `ChargedRingField` 与 `charged_ring` 预设：电流线圈的静电孪生，Paxton 立体角闭式给出电通量函数，种子围绕两个截面按等通量求根；
- `DielectricSphereField` 与 `dielectric_sphere`/`conducting_sphere` 预设：由边界条件决定的分段解析场，响应新增 `regions`，种子按 $\mathbf D$ 通量函数等分；
- 追踪器新增 `interfaces`：在场不连续的曲面上以事件停下并在另一侧重启，折射点落在界面上；
- 参考页新增带电圆环画法与交互式斜率场案例的勘误。

## v0.3.6：前端结构与显示图层

状态：**已完成**。

- app.js 拆成纯渲染器、请求状态机、响应校验和格式化四个模块，拆分前后 11 个预设在两种视口、两种像素比下的画布与页面读数逐字节相同；
- 图框左侧的竖向工具栏提供热图、场线、方向、场源、网格五个图层开关，切换零请求；关热图连色标一起隐藏，关场源禁止拖动，待重算状态优先；
- 探针吸附到最近的网格点并在图上标出；对数色标标出十的整数次幂；拖动中同步坐标输入框；
- HTTP API 与 Python 代码不变。无向短线段图层需要向量分量，随矢量契约一起进入下一版。

## v0.3.7：矢量契约与光标播种预览束

状态：**已完成**。

- 响应附带与标量同一次求值的 `vector` 网格（面内分量 `u`、`v`，`null` 与 `scalar.mask` 逐点一致）；
- 请求接受 1–16 个手动 `seeds`，服务端用该预设的追踪器双向积分并以 `seed_index` 标出，手动种子不占预算、另记 `manual_*` 统计；
- 前端新增无向的斜率短线图层和光标预览束图层：预览束由浏览器对向量网格插值加 RK4 得到，明写“不是服务端积分”，点击后交给服务端得到精确线；探针显示方向角与分量；
- 滑块松手提交、后发请求胜出；切换图层不再改变图框几何。

## v0.3.8：磁静态与闭合场线

状态：**已完成**。

- 无限长直导线，以及同向／反向双平行导线的横截面磁场；
- 有限长螺线管，采用有限个同轴理想圆电流环叠加的离散绕组近似；
- Helmholtz 与反 Helmholtz 线圈组，分别展示中心近匀强场与零场／梯度结构；
- 接入现有热图、向量探针、闭环追踪、光标预览和手动播种；明确场模型、播种策略、奇点排除与固定几何的适用范围。
- 六个预设首版采用固定电流与几何、覆盖播种；螺线管和同向线圈组在中平面分段覆盖主磁通与可见回流。新增场景使用适合较小导线排除区的闭环最短弧长，避免近导线小环重复绕行。

## v0.3.9：二维 Laplace、斜率场与理想材料边界

状态：**已完成**。

- `LaplaceField` 实现二维谐波多项式势的负梯度，首版提供鞍点与三阶多极两个无量纲预设；以势的梯度、无散无旋和谐共轭沿线不变作解析验收。
- `SlopeField` 将一阶方程 $y'=f(x,y)$ 表为 $(1,f)$；首版提供线性与 Logistic 两个无量纲预设，以解析解和水平平衡解验收。Python 可传入向量化 callable，Web 不接受自定义表达式。
- `MagneticShieldCylinderField` 实现无限长、线性各向同性、恒定相对磁导率圆柱壳在横向匀强磁场中的解析基准，展示筒壁磁通集中与内腔场减弱；以屏蔽因子、两界面法向 B/切向 H 连续和通量函数验收。
- 五个预设复用热图、向量探针、无向斜率短线、光标预览与手动播种；采用明确标注的覆盖播种，材料壁不作奇点遮罩，追踪器在两条圆界面上定位并重启。
- 该屏蔽筒不是有限长坡莫合金实物的完整材料模拟，不包含端部、开口、多层、饱和、磁滞或涡流；首版也不提供任意边值问题的通用 Laplace 求解器。

## v0.3.10：非定常流与物理时间

状态：**已完成**。

- `TimeDependentField` 与 `OscillatingFlowField` 建立含时速度场接口；冻结观察时刻后复用原有场线追踪器，新增独立 `PathlineTracer` 按 $d\mathbf x/dt=\mathbf u(\mathbf x,t)$ 积分。
- `flow_oscillating` 与 `flow_steady` 提供二维非定常振荡流和定常对照，以独立解析解验收流线、迹线、脉线的区别与定常极限。脉线是固定位置在不同释放时刻发出的粒子，在同一观察时刻的位置集合。
- 坐标、速度和时间分别使用 m、m/s、s；Web 提供 0–6 s 内的观察时刻、初始时刻与释放时间窗，默认观察 4 s。明确等时单点、出域、非有限值与实际终止时间的处理，冻结网格只描述观察时刻。
- 请求与响应公开时间契约，曲线缓存键包含时间；图例区分三类曲线，旧静态场景及其时间无关的交互保持原契约。

本版完成实现与本地验收；实际验证记录见[开发指南](development.md)，跨平台结果以发布提交的 CI 记录为准。不包含通用流体 PDE 求解器或振荡电偶极子的迟滞电磁场。

## 后续顺序

1. **含时电磁场**：扩展振荡电偶极子的迟滞电磁场，分别表达瞬时电场线、磁场线与能流。时间控制可以复用，流体轨迹与电磁场线的物理含义分别说明。
2. **自定义表达式与数值数据接入**：接入网格场及其坐标、单位、遮罩和插值契约；有限长、开口和多层磁屏蔽筒的数值解在此阶段接入，说明材料模型、端部漏磁与求解误差。
3. **三维视图与更多动力学**：三维场线、粒子轨迹及相对论动力学等，分别定义其模型与验证范围。

上述后续专题尚未分配版本号；v0.3.10 不包含振荡电偶极子或通用数值求解器。
