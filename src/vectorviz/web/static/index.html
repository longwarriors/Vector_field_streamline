⌖ 读图与交互

拖动场源改变位置；移动指针可探测坐标与场强。

  • 颜色表示色标标题所写物理量的大小；对数色标按数量级着色。
  • 色标上下限只是显示范围：尖角表示有格点超出范围、按端色显示，精确值请用探针。
  • 场线上的箭头只标方向：足够长的线按屏幕弧长放 1–3 个，很短的线不放；箭头大小固定，不表示强弱。
  • 场线疏密取决于播种方式和预算，不能直接读成场的强弱；圆环为等通量播种，见“播种说明”。
  • 探针显示指针坐标，以及离它最近的网格点上的原值（未按色标截断、不插值）。
  • 斜线区未着色：场源排除区（半径为数值设定）或非有限值；对数色标下为 0 的格点也不着色。
